🎯 Design Philosophy
Sahaayak is designed around four core principles:


Inclusive by Default: Optimized for rural, semi-literate, and vision-impaired users

Voice-First, Not Voice-Only: Primary interaction via voice, with fallback to touch

Trust Through Clarity: Government-grade security aesthetic with transparent data flows

Alive & Responsive: Micro-interactions that confirm every user action

📱 Responsive Design Breakpoints
Breakpoint System
Mobile:        < 600px   (phones, small tablets)
Tablet:        600px - 1024px  (landscape phones, tablets)
Desktop:       1024px - 1440px (laptops, small screens)
Large Desktop: > 1440px  (large monitors, 2K+)

Mobile (< 600px)


Sidebar: Hidden (collapsed to bottom nav bar)

Navigation: 5-icon bottom tab bar (50px height)

Font Sizes: Base 16px (prevent zoom on input focus)

Spacing: 8px base unit (tighter layouts)

Cards: Full-width with 8px gutters

Buttons: 48px minimum tap target (accessibility)
♿ Accessibility & Compliance
WCAG 2.1 AA Compliance Checklist
Visual & Contrast


✅ 1.4.3 Contrast (Minimum): All text meets 4.5:1 ratio (AA) or 7:1 (AAA)

✅ 1.4.4 Resize Text: All content readable at 200% zoom

✅ 1.4.10 Reflow: Content reflows single column on narrow screens

✅ 1.4.11 Non-text Contrast: UI components have 3:1 contrast minimum
Keyboard Navigation


✅ 2.1.1 Keyboard: All functionality accessible via keyboard (Tab, Enter, Escape)

✅ 2.1.2 No Keyboard Trap: Focus never trapped, always escapable

✅ 2.4.3 Focus Order: Logical, predictable tab order

✅ 2.4.7 Focus Visible: 2px blue outline on all focusable elements
Screen Reader Support


✅ 1.3.1 Info and Relationships: Semantic HTML (<button>, <nav>, <main>)

✅ 2.4.1 Bypass Blocks: "Skip to main content" link

✅ 4.1.2 Name, Role, Value: All interactive elements have ARIA labels

✅ 4.1.3 Status Messages: Live regions for alerts, toasts, notifications
Text & Language


✅ 3.1.1 Language of Page: lang="en" and lang="hi" attributes set

✅ 3.1.2 Language of Parts: Dialect-specific content marked (Bhojpuri, etc.)

✅ 3.3.1 Error Identification: Clear, color-independent error messaging

✅ 3.3.4 Error Prevention: Confirmation dialogs for critical actions
